# Ashish Tiwari Portfolio

## Run locally on Windows
1. Extract this ZIP.
2. Double-click `RUN_WEBSITE.bat`.
3. Keep the terminal window open while using the site.

## Contact form
The contact form submits directly to `ashishtiwari00003@gmail.com` through FormSubmit, so the visitor does not need to open their own email app. On the first submission, FormSubmit may send an activation email to the portfolio owner. Open that email and confirm activation before expecting messages to be delivered. This uses a third-party form service; do not submit sensitive information through it.

The frontend itself can be run without configuring the MongoDB backend for the contact form.
